# Classroom Management

Classroom booking and usage dashboard with booking management, classroom lists and statistics; includes database design, SQL scripts and import/export resources.

## Technology stack

Node.js, Express, JavaScript, JSON-backed runtime storage and SQL design artifacts. `sql.js` is listed as a dependency.

## Getting started

Run `cd app`, `npm ci`, then `npm start`; open `http://localhost:3000`.

## Testing

No test command is currently configured in the inspected app/package.json.

## Scope and limitations

The current application stores records in `app/arvutiklass.db.json`.
